# Remote Control Agent v0.1.27-rc.1 — Reliable two-phase protected browser handoff

This prerelease keeps the three existing signed, owner-authorized Remote Control handoff tools while making the one-time OTP-protected browser link deliverable within ChatGPT's short MCP request time limit.

- First `browser_handoff_request(session_id)` synchronously blocks all ordinary device tools and writes a fail-closed intent marker, then immediately returns `preparing`. Native Windows performs the bounded Cloudflare Quick Tunnel preparation and strict unauthenticated GET 302 authorization challenge (including expected redirect host/path, state cookie), followed by anonymous POST 401, before opening human input.
- `browser_handoff_status` always returns redacted state, with no URL, secret or browser content. After `link_ready`, repeat `browser_handoff_request` using the **original browser session_id** to claim the URL once from Agent process memory. Wrong-session and duplicate claims cannot retrieve it; a lost claim reply requires explicit return and a new handoff.
- Explicit return during `preparing` requests cancellation, stops an already-attached local controller immediately, and keeps ordinary AI tools blocked until cleanup completes and a subsequent explicit return confirms `ai`. Late connection callbacks cannot revive revoked human access. Expiry, revocation and Agent restart never reissue the link or admit AI automatically.
- URL/token are never persisted to receipts, files, Durable Objects or status. SQLite receipt teardown waits for in-flight preparation. The single user-owned browser context and prior transactional Windows scheduled-task upgrade/rollback rules remain unchanged.
- The existing 15-minute human takeover lifetime and 90-second Quick Tunnel protection deadline remain unchanged. This prerelease does **not** relax the Cloudflare Access email OTP or POST 401 verification.
- The matching MCP tool descriptions were updated in [mcp-workers PR #317](https://github.com/lirtual/mcp-workers/pull/317) without adding any new tools or services.
