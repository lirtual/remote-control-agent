# Remote Control Agent v0.1.19

- One-line Windows installer completes the verified upgrade and signed grant check without requiring manual `re-pair` and `start` commands.
- Healthy grants remain unchanged. A missing grant needs one authenticated MCP owner approval; the original Ed25519 private key and local receipts are retained.
- Windows CLI and install prompts use short English-only messages and `Permanent` / `Temporary` labels.
- Noninteractive first install fails closed. Existing paired-device verification can run from a piped installer.
- Native Windows, Linux x64 and Linux arm64 regression tests pass. Windows installation and signed online state remain separate acceptance checks.
- Existing device processes are not changed by publishing this release.
