# Remote Control Agent v0.1.21

- Linux now uses the canonical `remote-control-agent.service` systemd unit and `REMOTE_CONTROL_AGENT_*` runtime environment names.
- Existing signed-WSS device identity, grant, immutable executable pin and historical SQLite operation receipts are preserved.
- Explicit owner-terminal offline cutover from the reviewed historical WSS, loopback and Tunnel units has exact-template, identity, CPU and program guards plus a durable rollback journal.
- Automatic rollback restores the original service atomically after a failed activation. Crash recovery is explicit and checks backup integrity.
- The normal one-line Linux installer is unchanged. To migrate a verified historical installation, use the reviewed Worker's explicitly enabled `--upgrade` entry only after all three former user units have been stopped locally.
- New binaries do not silently retire, delete or rotate an existing device or Cloudflare Tunnel. Owner-authorized retirement of obsolete units, Tunnel resource and migration backup happens only after independent live WSS/MCP and historical-receipt acceptance.
- Windows keeps its existing same-key/native task upgrade behavior.
