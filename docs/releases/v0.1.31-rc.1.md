# Remote Control Agent v0.1.31-rc.1 — bounded iPhone OTP return-query handling

This is a narrowly scoped **candidate fix and diagnostic enhancement** for [Spec #280](https://github.com/lirtual/mcp-workers/issues/280). On a real iPhone Safari OTP test using `v0.1.30-rc.1`, the user saw `{}` after OTP and the Agent reported `diagnostic_code=document_denied_path` twice **before explicit return**. This proves that at least one document GET reached the local controller but was refused as an unsupported path/query. It **does not establish the exact failed URL**, prove that Cloudflare appended query metadata, or confirm end-to-end OTP success.

## Changes

- Permit bounded, inert post-OTP return-query metadata only when the incoming request-target is rooted at `/?`, has at most four total query parameters and 512 characters, and carries **exactly one** `handoff_token` matching the **currently minted token** by constant-time comparison. This tightens token verification compared with the previous format-only check.
- Reject wrong/absent/replayed/duplicate tokens, wrong paths/hosts, and oversized/malformed requests. Continue to serve the existing root `/` HTML for cookie-authenticated resume only, with no credential-bearing external resource loads. Inert query metadata is not reflected and client code strips the entire URL via `history.replaceState`.
- Add fixed, non-sensitive `document_denied_token_missing` to distinguish a stripped token from other rejected root-query URLs without persisting or returning the raw requested path or query.
- Extend local controller HTTP and parser regression tests for allowed bounded metadata, query reordering, wrong/duplicate tokens, wrong path/Host, oversized input, and preserved controller exchange security.

No changes to `cloudflared`, Quick Tunnel OTP `--allowed-mail`, Host/Origin/CSRF validation, session or one-shot token exchange, browser input controls, deadline, permanent pairing, login email, logging, services, or Worker. No new MCP tool, database, auth proxy, or additional deployment environment.
