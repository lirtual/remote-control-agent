# Remote Control Agent v0.1.9 — Full Tools (Prerelease)

This immutable test prerelease introduces a `paired-full-v1` runtime for **approved, paired Linux/WSL2 devices**. It enables file reads and writes, file search, Shell commands and managed sessions without per-feature `readOnly`, `writeFile` or `shell` flags. Commands run as the local non-root Agent user.

Authentication still requires owner-mediated pairing and signed WSS. Device revocation, operation-id deduplication, durable SQLite receipts and local identity remain unchanged.

## Compatibility and rollout

- Native Linux x64 and ARM64, bundled Node.js 24.21.0, glibc/kernel prerequisites unchanged. Native Windows support is separate and **not** included.
- A reviewed, installer-owned **read-only/no-Shell** permanent Agent can be promoted to this release **once**, using its Worker-hosted, pinned `/install.sh --upgrade` path. The old `rca upgrade` CLI is not a supported migration entry because it cannot recognize the new runtime profile.
- **Full-tools → full-tools in-place upgrades are deliberately blocked** until authoritative managed-session quiescence is supported; this release must not interrupt ongoing Shell sessions.
- A local uninstall does **not** revoke remote access; remote device revocation is a separate authenticated MCP operation.
