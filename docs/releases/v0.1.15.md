# Remote Control Agent v0.1.15

Single-maintainer reviewed three-platform pinned prerelease for Spec #24; the Release workflow publishes it on approved pin updates and does not inspect repository immutability settings.

- Linux x64 / ARM64: native self-contained agent, interactive permanent/temporary mode selection, single owner-MCP pairing, safe first-activation recovery and repeat-install behavior.
- Windows x64: native PowerShell verified bootstrap, interactive onboarding, signed device grant verification, normal-user logon task for permanent grants, foreground temporary sessions, safe interrupted activation recovery.
- No existing device is automatically re-paired, upgraded or restarted by publishing this release.
- Distribution via the public Worker installer requires a separate reviewed source and SHA-256 pin, Worker deployment, and live HTTP verification.
- True clean-device owner approval, signed WSS online status, harmless read and Cloudflare public-path acceptance remain mandatory Spec #24 post-deployment checks.
