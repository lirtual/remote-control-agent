# Remote Control Agent v0.1.16

Windows same-command first installation or explicitly confirmed upgrade.

- Existing paired Windows devices may use the same public PowerShell installer URL as clean installs. The installer detects the current SID-bound user-logon task and current version, displays the planned target and asks for one explicit confirmation; no unattended version switch.
- The new candidate is staged only after pinned GitHub Release source and SHA-256 verification, native ZIP inventory validation and private ACL checks. The candidate's existing `rca upgrade` performs the task/identity validation, transactional switch and rollback. The stored device ID, private key, Worker endpoint, cloud grant and prior program versions are preserved. Tasks intentionally stopped before upgrade remain stopped.
- Missing tasks, orphaned identities, unsafe scheduled-task executables, untrusted archives and downgrades remain fail-closed. Cancellation before download does not replace a running Agent or perform pairing.
- Fresh devices retain the interactive permanent/temporary install and one authenticated MCP owner approval.
- Linux x64/ARM64 native packages and Windows native browser/full-tool packages remain independently verified.
- This immutable Release alone does not change any existing device. The public Worker must be separately updated to pin this release and the SHA-256 of this installer source, and a real paired Windows device must complete a signed WSS verification after owner-confirmed upgrade.
