# Remote Control Agent v0.1.20

- Windows installer approval uses a direct console-key prompt, `Upgrade? [y/N]`, instead of the PowerShell host's locale-dependent choice UI.
- Only Y/y approves. Enter, No, other keys, and unsupported terminal input never authorize a version switch.
- Successful verification no longer prints machine-readable manifest JSON. Digest checks, error reporting and side-by-side upgrade remain unchanged.
- Same-key grant recovery and one-line Windows installation retain the v0.1.19 security gates and user-approved MCP pairing.
