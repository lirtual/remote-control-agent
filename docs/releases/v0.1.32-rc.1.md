# Remote Control Agent v0.1.32-rc.1 — iPhone post-exchange screenshot diagnostics

Diagnostic-only prerelease for [Spec #280](https://github.com/lirtual/mcp-workers/issues/280). It does **not** claim that remote screenshot/control is fixed.

## Last real-device evidence

On iPhone Safari and paired Windows Agent v0.1.31-rc.1, Cloudflare email OTP returned the HTML controller with a tab-1 dropdown and command buttons. An error reported "Controller unavailable, expired, or already claimed", and no remote screenshot appeared. While still live, `browser_handoff_status` twice returned `state=interactive, diagnostic_code=exchange_completed`, indicating successful one-time token exchange; the screenshot request failure category was not yet observable. Explicit return succeeded, AI control restored, browser `uncertain=false`, and new tab identities/snapshot were verified. No claim of successful human input or screenshot is justified.

## Changes

Only [PR #54](https://github.com/lirtual/remote-control-agent/pull/54) changes, merged into `main` at `8b9eb25aadeb06b7c59b102d75a749ac8fa0c54e`:

- Add allowlisted, fixed post-exchange controller diagnostics to the existing authenticated `browser_handoff_status.diagnostic_code`: `tabs_served`, `screenshot_requested`, `screenshot_served`, `screenshot_denied_precheck`, `screenshot_denied_session`, `screenshot_denied_csrf`, `screenshot_denied_output`, `screenshot_failed`.
- Browser handoff client displays the numeric HTTP error status instead of mapping every non-429 rejection to the same "already claimed" message. No URL, Cookie, OTP, assertion, tunnel hostname, bearer token, screenshot pixel, raw request body, exception or internal stack is exposed via diagnostics.
- Regression tests exercise successful screenshot, missing Cookie, wrong CSRF, backend screenshot exception and safe UI reporting.
- No new MCP tool, storage, Worker, secret, Tunnel, auth proxy or debug logs. Keep existing `--allowed-mail`, strict Host/Origin/CSRF/session/one-use exchange, timeout, human-input limits and explicit return.

Review: independent human security review **owner-approved Waived / Not performed (NOT Pass)**, specifically for PR #54. The recorded waiver is not a peer review. PR CI #40344438735 and PR-branch manual CI #40345325105 each passed all three platforms, including the latter's native Windows protected Quick Tunnel challenge.
